# MVP 核心流程说明

## 1. 流程定位

V0.1 的核心演示由三部分组成：

- 学生学习主界面：承载学生与灵灵老师的真实学习互动。
- 系统观察面板：展示系统读取了什么、判断了什么、为什么切换策略、写回了什么。
- 报告预览：展示未来面向教师和家长的学习摘要与建议。

主流程的目标是证明：

> 灵灵老师不是普通 AI 问答工具，而是能基于长期记忆、主动感知、启发式教学、幽默调节和画图辅助，形成结构化学习闭环的 AI 伴学系统。

## 2. MVP 主流程

```mermaid
flowchart TD
    A["进入桌面端演示应用"] --> B["打开学生学习主界面"]
    B --> C["系统生成或展示当前学习任务"]
    C --> D["学生输入题目、答案、追问或困惑表达"]
    D --> E["教学编排器接收学习事件"]

    E --> F["忆感模块：读取学生画像与历史学习记录"]
    E --> G["深图模块：分析题目、知识点、错因和解题路径"]
    E --> H["状态识别：分析当前行为信号与表达"]

    F --> I["教学编排器融合上下文"]
    G --> I
    H --> I

    I --> J{"是否需要策略切换？"}

    J -- "否：状态平稳" --> K["继续启发式教学"]
    J -- "是：困惑/挫败/疲惫" --> L["切换为主动关怀 + 拆小步引导"]

    I --> M{"是否需要视觉辅助？"}
    M -- "是" --> N["调用画图辅助：图形、高亮、标注或示意"]
    M -- "否" --> O["保持文本/对话引导"]

    K --> P["生成本轮教学回应"]
    L --> P
    N --> P
    O --> P

    P --> Q["学生继续互动"]
    Q --> R{"本次学习是否结束？"}

    R -- "否" --> D
    R -- "是" --> S["生成本次学习复盘"]

    S --> T["写入结构化学习事件"]
    T --> U["更新学生画像与长期记忆"]
    U --> V["生成后续主动复习任务"]

    V --> W["系统观察面板展示决策链路"]
    V --> X["报告预览生成教师/家长可读摘要"]
```

## 3. 系统观察面板流程

系统观察面板不是正式学生功能，而是 V0.1 演示和验证用的辅助界面。

```mermaid
flowchart TD
    A["学习事件发生"] --> B["展示读取到的历史记忆"]
    B --> C["展示当前题目识别结果"]
    C --> D["展示状态识别信号"]
    D --> E["展示教学策略选择原因"]
    E --> F["展示本轮调用的能力模块"]
    F --> G["展示写回的结构化数据"]
    G --> H["展示生成的主动复习任务"]
```

观察面板需要让观众看到：

- 读取了哪些历史学习记录。
- 当前题目命中了哪些知识点或薄弱点。
- 系统检测到哪些状态信号。
- 教学编排器为什么改变策略。
- 本次学习写回了哪些数据。
- 后续复习任务如何产生。

## 4. 报告预览流程

报告预览用于证明系统未来可以服务教师和家长，但 V0.1 不实现完整教师端和家长端。

```mermaid
flowchart TD
    A["本次学习结束"] --> B["汇总结构化学习事件"]
    B --> C["生成学生学习摘要"]
    C --> D["生成教师视角摘要"]
    C --> E["生成家长视角摘要"]

    D --> F["教师视角：知识点、错因、干预记录、复习建议"]
    E --> G["家长视角：学习状态、完成情况、陪伴建议、后续计划"]
```

报告预览不展示完整原始对话，优先展示结构化摘要和可操作建议。

## 5. 流程边界

V0.1 主流程不处理以下内容：

- 完整教师端后台。
- 完整家长端。
- 班级管理。
- 支付、订阅、账号找回。
- 真实学校或区域教育平台接入。
- 全学段、全学科、全题型覆盖。
- 心理诊断或心理治疗。

V0.1 的重点是跑通一条可解释、可演示、可沉淀数据的学习闭环。
