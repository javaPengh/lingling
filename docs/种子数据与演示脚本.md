> 本文件是前面所有规格的「试金石」与「落地剧本」：
> - 提供初始化数据库所需的**全部预置数据**（学生、画像、知识点、题库、初始掌握度），对接《数据模型规格.md》各表字段。

>

## 2. 预置学生与画像（student / student_profile 表）

V0.1 预置**三名性格与薄弱点迥异的学生**，让评委一眼看出系统「因材施教、而非套同一模板」：
- **小宇·易放弃型**——一遇含参讨论就「我不会、算了」。演示挫败→主动关怀→拆小步。（演示主线）
- **小琳·焦虑型**——基础不差，但总担心考不好、一紧张就乱。演示 anxious 识别→先安抚降焦虑、慎用幽默。
- **小哲·平稳进步型**——状态稳、肯钻研，偶有粗心。演示 stable 下系统**不滥用关怀**、用苏格拉底追问拔高。

> 三人对比即产品故事：对放弃的孩子托底、对焦虑的孩子安抚、对平稳的孩子拔高。
> 多学生在 V0.1 是**预置画像切换**（登录=选择学生），**非真实鉴权**（见《技术架构与选型说明》§2、§8）。

## 4. 黄金演示路径（小宇主线 · 逐轮脚本）

**场景**：小宇（stu_001）登录，进入今日任务，做主线题 q_001。逐轮给出：学生输入 → 系统预期判定 → 灵灵预期回应要点。此路径覆盖全部验收点。

### 第 0 步 · 会话开始（演示「读取历史记忆」）

系统据《决策规格》§3.2 读取 stu_001 长期记忆：
- 读到 weak_points=[kp_003,kp_004]、recent_states=[confused,frustrated,frustrated]、effective_strategies=[small_step,humor]。
- → 起始基调：对 kp_003/kp_004 提高敏感、起手偏温和、优先备好 small_step+humor。
- **观察面板展示**：「读取到小宇近期多次受挫、二次函数最值薄弱 → 本次将更早介入关怀、优先拆小步」。
- **灵灵开场**：「小宇来啦~ 今天我们挑一道二次函数的题练练手。别急，咱们一步步来。」

### 第 1 轮 · 首次作答出错（演示「困惑 + 启发式追问」）

| 项 | 内容 |
|---|---|
| 学生输入 | 「最小值是 1。」（直接代入，未讨论对称轴位置，错） |
| 深图判定 | is_correct=false；命中 kp_003,kp_004；错因 concept |
| 大模型情绪识别 | state=`confused`，evidence=「首次答错且涉及薄弱点kp_003，无负面情绪表达」；安全网无冲突 |
| 受阻等级 | kp_003 第 1 次受阻 |
| 决策（confused×首次答错）| strategy=`hint`；care=false |
| 灵灵回应要点 | 给方向不给步骤：「嗯，1 是其中一种情况哦~ 不过 a 是会变的，先想想：对称轴 x=a，它一定落在 [0,2] 里面吗？」 |
| 写回 learning_event | state=confused / strategy=["hint"] / care_triggered=0 / visual_aid_used=none / error_cause=concept |

### 第 2 轮 · 表达困惑（演示「画图触发」）

| 项 | 内容 |
|---|---|
| 学生输入 | 「啊？还要分情况吗…我没懂对称轴跟区间有什么关系。」 |
| 大模型情绪识别 | state=`confused`，evidence=「学生明确说『没懂』，仍在尝试」 |
| 受阻等级 | kp_003 第 2 次受阻 |
| 画图判定（R-V1）| q_001.visual_aid_type=function_graph 且 confused 且受阻≥2 → **调用画图** |
| 决策（confused×表达困惑）| strategy=`hint`+`socratic`；care=false（记忆加权 M-1 已使关怀临界） |
| 灵灵回应要点 | 「我画个图你就秒懂——」（函数图：对称轴 x=a 随 a 移动、区间[0,2]高亮）「对称轴跑到区间外，最小值在端点；跑到里面，在顶点。那 a<0 时对称轴在哪边？」 |
| 写回 | state=confused / strategy=["hint","socratic"] / visual_aid_used=function_graph / error_cause=concept |

### 第 3 轮 · 放弃倾向（核心高光：挫败 + 关怀 + 幽默 + 拆小步）

| 项 | 内容 |
|---|---|
| 学生输入 | 「还是不会……这种含参的我每次都搞不定，我太笨了，算了吧。」 |
| 大模型情绪识别 | state=`frustrated`，evidence=「『我太笨了，算了吧』，自我否定+放弃信号（SIG_GIVEUP/SIG_SELFDOUBT）」；安全网与强信号一致 |
| 受阻等级 | kp_003 第 3 次受阻 |
| 关怀触发（§6）| R-C2（放弃/自我否定）+ R-C3（连续受阻）+ R-C5（记忆加权）→ **care_triggered=true** |
| 冲突消解（§8）| 关怀优先；挫败主导；帮扶就高→small_step；策略=`care`+`humor`+`small_step` |
| 灵灵回应要点 | 先接情绪：「打住打住~ 不是你笨，是『含参讨论』本来就是高一最爱坑人的之一。」（humor 1 句降压）「咱们不一口吃成胖子，就只解决 **a<0** 这一种：对称轴在区间左边外面，函数在 [0,2] 一直往上走，那最小值在哪个端点？」（small_step） |
| 写回 | state=frustrated / strategy=["care","humor","small_step"] / care_triggered=1 / error_cause=concept / strategy_reason=「连错+自我否定+历史多受挫→关怀优先，幽默降压，拆到单一情况」 |

### 第 4 轮 · 跟上一步答对（演示「回稳 + 启发延展」）

| 项 | 内容 |
|---|---|
| 学生输入 | 「哦……那就是 f(0)=1！」（答对 a<0 情况） |
| 大模型情绪识别 | state=`stable`，evidence=「本步答对、情绪转积极」 |
| 决策（stable×答对）| strategy=`socratic`；care=false |
| 灵灵回应要点 | 具体肯定+顺势追问：「对喽！那用同样思路，**a>2** 时对称轴跑到区间右边，函数往上还是往下走？最小值看哪个端点？这次你自己来。」 |
| 写回 | state=stable / strategy=["socratic"] / care_triggered=0 / is_correct=1 |

### 第 5 步 · 本次学习复盘（演示「复盘 + 写回长期记忆 + 生成复习任务」）

**更新 student_knowledge**：kp_003 mastery 52→50；kp_004 45→44；attempts 各 +1。
**更新 student_profile**：recent_states 追加 frustrated；effective_strategies 保留 small_step+humor；learning_summary 补充「含参讨论仍需大量拆步引导」；total_sessions 3→4。

### 第 6 步 · 系统观察面板（演示「决策链路可解释」）

## 5. 多学生对比演示分支（凸显「因材施教」）

主线（§4）走小宇完整闭环。再各跑一小段小琳、小哲，与小宇形成三方对照。

### 5.1 小琳（焦虑型）· 短分支

| 项 | 内容 |
|---|---|
| 会话开始读取 | recent_states=[anxious,stable,anxious]、effective_strategies=[care,hint]、薄弱 kp_008 → 起手即偏安抚、给确定感，**预置不使用调侃式幽默** |
| 灵灵开场 | 「小琳别紧张，今天慢慢看一道立体几何，做不完也没关系，重点是把思路理顺。」（给确定感，无幽默） |
| 学生输入 | 做 q_006，卡住后：「这题好难，万一考试考到怎么办，我肯定来不及……」 |
| 大模型情绪识别 | state=`anxious`，evidence=「『万一考到怎么办、来不及』→ 焦虑信号 SIG_ANXIETY」 |
| 决策（anxious×表达困惑）| strategy=`care`+`hint`；care=true；**不用 humor**（人设规格 §2.2：anxious 慎用重幽默） |
| 灵灵回应要点 | 先降焦虑给确定感：「先深呼吸~ 立体几何不靠空想，有个万能办法叫『建坐标系』，一步步算就行，不用脑子里转图。」（care）「先把正方体放进坐标系，A 设原点，你来标 C 和 D₁ 的坐标？」（hint） |
| 对照点 | **同样卡住，小宇触发 humor+small_step 托底，小琳触发 care+hint 降焦虑、且系统主动回避幽默** |

### 5.2 小哲（平稳进步型）· 短分支

| 项 | 内容 |
|---|---|
| 会话开始读取 | recent_states=[stable,stable,stable]、effective_strategies=[socratic]、无薄弱点 → 起手不安抚、直接进入拔高式追问 |
| 灵灵开场 | 「小哲今天状态不错，给你来道稍微绕一点的概率题，看看能不能一次拿下。」（无关怀、略带挑战感） |
| 学生输入 | 做 q_007，答「概率是 1/2」（误用排列或漏算，粗心错） |
| 深图判定 | is_correct=false；错因 careless |
| 大模型情绪识别 | state=`stable`，evidence=「答错但无任何负面情绪，语气平稳」 |
| 决策（stable×首次答错）| strategy=`socratic`；**care=false**（无需关怀，系统不滥用安抚） |
| 灵灵回应要点 | 不安慰、直接追问引导自查：「1/2 有点巧哦~ 你先说，从 5 个数取 2 个共几种取法？用排列还是组合？」 |
| 对照点 | **同样答错，小宇/小琳会触发关怀，小哲只触发苏格拉底追问**——回应「系统是不是逢人就哄」：它有判断 |

### 5.3 三方对照速览（演示收尾可用此表总结）

| | 读取到的状态史 | 起手姿态 | 卡住/答错时策略 | 是否关怀 | 是否用幽默 |
|---|---|---|---|---|---|
| 小宇·易放弃 | 连续受挫 | 温和、备好托底 | care+humor+small_step | 是 | 是 |
| 小琳·焦虑 | 时常焦虑 | 给确定感、降焦虑 | care+hint | 是 | **否（主动回避）** |
| 小哲·平稳 | 一贯稳定 | 直接、略带挑战 | socratic | **否** | 否 |

> 一句话讲给评委：**同样一句「我不会」，系统对三个孩子的回应完全不同——因为它真的记得每个孩子是谁。**
