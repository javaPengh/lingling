# 实施历史与变更记录

本文档是项目的事实账本,记录每个关键开发任务实际完成了什么。

`docs/` 下其他文档均视为计划、规格或参考材料。计划可以调整,规格也可能迭代;当实际实现与这些文档不一致时,以本文档记录的实际情况和变更原因为准。

记录规则:

- 按较大的任务块记录,不写过细流水账。
- 只写关键实施结果、涉及范围、与计划/规格不一致的地方及原因。
- 如果不清楚变更原因,先向项目负责人确认,不要自行猜测。
- 不记录验证结果,也不设置后续事项小节。

## 2026-06-01 | 登录页接入后端账号密码登录

### 实际完成

- 按 `docs/登录页.html` 的视觉结构实现前端登录页,包含左侧品牌区、账号/密码输入、记住我、密码显隐和演示账号提示。
- 登录页提交账号密码到后端登录接口,登录失败在表单内提示错误。
- 登录成功后根据后端返回的账号角色和目标页面分流:学生进入学习界面,家长进入家长报告视角,老师进入老师报告视角。
- 删除旧学生选择页在应用入口中的使用,移除产品内四 tab 导航结构。
- 前端补充登录 API 类型与 client 调用,与后端 `LoginResponse` 的 camelCase 字段保持一致。

### 与计划/规格不一致的地方

- 旧 T1-4 曾描述为“列出预置账号供选择”;实际实现为账号密码登录页。
- 变更原因:登录页原型已确定为账号密码表单,并且项目负责人明确要求前端按账号密码登录后进行角色分流。

## 2026-06-01 | 账号密码登录与角色分流后端

### 实际完成

- 将预置账号从“直接选择进入”升级为“账号密码登录后进入”。
- `account` 表增加登录用户名和密码哈希字段,种子账号写入稳定的演示密码哈希。
- 新增登录接口,账号密码校验成功后返回账号角色、可查看学生范围和前端目标页面。
- 登录分流规则为:学生账号进入学生学习界面,家长账号进入家长报告视角,老师账号进入老师报告视角。
- 旧本地库启动时会自动补齐账号登录字段和缺失的演示账号凭据。

### 与计划/规格不一致的地方

- 计划文档和数据模型规格仍描述为“预置账号选择,不做真实鉴权”;实际改为登录页输入账号密码。
- 变更原因:登录页原型已确定为账号密码表单,项目负责人明确要求后端按账号密码登录并根据账号角色分流。

## 2026-06-01 | 三角色账号结构后端落地

### 实际完成

- 新增 `account` 与 `account_student` 两张表,用于表达学生、家长、老师三类预置账号及其可查看学生范围。
- 种子数据加入小宇、小哲、小琳三个学生账号,小宇的家长账号,以及王老师账号。
- 家长/老师账号通过 `account_student` 查询可查看学生;学生账号通过 `account.student_id` 指向本人。
- 新增账号列表接口和按账号查询可查看学生的接口,供后续登录入口页使用。
- 保留现有学生列表接口,避免当前前端学生选择页在登录入口改造前失效。

### 与计划/规格不一致的地方

- 早期界面被实现为并列的多 tab Web 应用;实际产品结构修正为学生、家长、老师三角色应用。
- 变更原因:项目主规格早期未把三角色登录结构写清楚,已在 `docs/项目主规格.md` 第 6、7 节和 `docs/数据模型规格.md` §4.10、§4.11 中补充明确。

## 2026-05-31 | 后端重做为 Python + FastAPI

### 实际完成

- 将 `server/` 从旧 Node + TypeScript 后端整体替换为 Python + FastAPI 后端。
- 保留 `server/db/schema.sql`,继续使用 SQLite 建表语句。
- 按 `api / services / dao / models / llm / core / scripts` 组织后端代码。
- 用 Python 改写种子数据与验证脚本,保留原有演示数据内容。
- 补齐学生列表、学习会话、学习回合、会话结束写回、观察面板、报告预览等后端闭环接口。
- LLM 层提供 `mock` 与 `deepseek` 两种接入模式,默认用 `mock` 支持离线演示。

### 与计划/规格不一致的地方

- 原早期技术方向包含 Node + TypeScript 后端;实际改为 Python + FastAPI。
- 变更原因:项目要服务于 AI/agent 方向技术积累,Python 生态与 DeepSeek、后续 agent 工具链更契合。

## 2026-06-01 | 学生选择页实现与布局调整

### 实际完成

- 参考 `docs/学生选择页原型.html` 和 `docs/学生选择页面.png`,在 `web/src/pages/StudentPicker.tsx` 实现学生选择页。
- 学生列表通过 `GET /api/students` 获取,页面根据接口返回的学生数据渲染入口卡片。
- 按原型补充三位演示学生的头像字、班级文案、学习节奏短句和卡片配色。
- 将学生选择页调整为全屏应用式布局:左侧橙色品牌区贴住浏览器左侧和上下边缘,右侧顶部导航与主体内容连为一个整体,去掉最外层浮层、圆角和背景边距。

### 与计划/规格不一致的地方

- 学生姓名、数量和 ID 来自后端接口;但班级文案、头像字、学习节奏短句和卡片视觉配色暂时由前端按原型映射。
- 变更原因:当前学生列表接口只提供学生选择页所需的基础数据,而这些内容属于 T1-4 原型展示层包装,改动成本低,本轮按页面原型优先落地。
