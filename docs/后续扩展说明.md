**后续扩展规划（V0.2 方向）**

V0.1 验证核心闭环后，计划向两个方向扩展：

**高中英语学科**：在现有「学生画像 + 状态识别 + 教学编排」架构基础上，扩充知识点体系（词汇、语法、阅读、写作）和对应的错因分类，补充英语题库种子数据。核心能力模块无需重写，主要工作量在学科内容层的扩充，以及针对英语题型的深图模块适配（如作文批改、语法分析）。

**GeoGebra 深度集成**：V0.1 画图方案采用 Plotly（函数图）+ 预置 SVG（几何图）满足演示需求。V0.2 引入 GeoGebra 用于实现「学生可动手操作的交互式几何探索」场景——这类功能 GeoGebra 是业界最强方案。引入前需解决两件事：一是商业授权问题（GeoGebra 当前为非商业免费协议，商用需与版权方谈授权）；二是集成复杂度评估（GeoGebra 嵌入 API 完备，但整体偏重，需评估对加载性能的影响）。



**现在回答你真正的大问题:从这个 0.1 原型,到一个能商业化运营的软件,要扩展什么、钱花在哪。**

我把它分成"技术扩展"和"持续花费"两块讲,因为它们性质不同——前者是一次性的开发投入,后者是上线后每月都要烧的钱。

**第一块·技术上要补哪些(从演示原型到能运营)**

你现在的 0.1 是个"单机本地演示",要变成"很多真实学生能用的软件",架构上有几处必须升级,这些是真实工作量:

一是**从本地搬到云端**。现在是你电脑上跑、浏览器打开。商业化要让全国学生都能访问,就得部署到云服务器,前端要能公网访问,后端要能扛多人同时在线。这是最大的一块改造。

二是**从 SQLite 换成正式数据库**。SQLite 适合单机,多人同时读写会扛不住。要换成 MySQL 或 PostgreSQL(这正好回到你熟悉的领域了)。——这也是为什么我之前建议把数据库读写收口在 dao 层,换库时上层不用动。

三是**做真正的用户系统**。0.1 是"选预置学生",商业化要有真实的注册、登录、密码、账号安全、数据隔离(每个学生只能看自己的数据)、支付订阅。这块是你主规格里明确排除在 0.1 之外的,商业化时要补齐。

四是**内容规模化**。0.1 只有 7 道题、9 个知识点。真要服务学生,需要成体系的题库(成百上千道)、完整的知识图谱、多学科(英语就在这里加入)。这是个持续的内容工程,可能要请学科老师参与,不只是写代码。

五是**合规与安全,这块对你尤其重要,因为你的用户是未成年人**。商业化运营涉及:用户数据隐私保护(《个人信息保护法》)、未成年人信息特殊保护、内容安全审核(尤其大模型生成内容要过审,不能输出不当内容)、可能还需要相关教育/网络资质备案。这块不是技术问题,但不做不能合法运营,而且未成年人产品监管更严。

六是**大模型这块要加东西**:内容安全过滤(防止模型输出不当内容给孩子)、调用监控和限流(防止被刷、防止单用户异常消耗)、可能要做缓存和提示词优化来控成本。这时候你之前问的向量数据库,如果做"相似题推荐""历史错题语义搜索"等功能,才真正派上用场。

**第二块·钱会持续花在哪(上线后每月烧的)**

这才是商业化和做 Demo 的本质区别——Demo 做完就不花钱了,运营是每月都要烧:

最大的两块是**服务器/云资源**和**大模型 API 调用**。服务器是你不管有没有人用都要交的固定成本(租云主机、数据库、带宽、存储),用户多了还要扩容。大模型调用则随用户量线性增长——这就是为什么单价便宜很重要:假设你有 1000 个活跃学生,每人每天若干轮对话,每轮两次调用,一个月累积的 token 量就很可观了。好在你选了 DeepSeek,它的单价在主流模型里属于最便宜的一档,这一块的成本压力比用海外模型小得多——这也反过来说明你选 DeepSeek 对商业化是明智的。

其他持续成本:内容维护(持续出题、更新)、可能的人力(运维、客服、学科内容)、合规相关的持续投入(安全审核、资质维护)、以及如果做 App 还有应用商店相关费用。

**给你一个判断框架,而不是具体数字**(因为具体数字取决于你的用户规模,现在算没意义):

Demo 阶段(现在):几乎零成本,DeepSeek 调用费可忽略。

小规模试运营(几十到几百用户):主要是一台云服务器的固定费(月几百元量级)+ 少量 DeepSeek 调用费。这个阶段总成本仍然很低,一个月几百到一两千元能覆盖。

规模化运营(成千上万用户):服务器要扩容、DeepSeek 调用费随用户增长、要投人力做内容和合规——这时候成本才会显著上去,但那时你应该已经有收入(订阅费)来覆盖了。

**最关键的一句话给你:** 商业化真正的成本拐点不在技术,而在"用户规模"和"合规"。技术扩展是一次性投入(而且你有 Java 底子,后端云端化对你不难);**大模型因为选了 DeepSeek 这种价格屠夫,反而是成本里最不用担心的一块**;真正要认真对待的是未成年人数据合规和内容安全——这块花的可能不只是钱,还有精力和资质门槛,建议你商业化前专门了解清楚
